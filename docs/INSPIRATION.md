# 交互设计参考

下列开源项目提供了交互设计启发。日日独立实现相应流程，未复制这些项目的源码、商标或媒体。

| 项目 | 参考方向 | 上游许可证 |
| --- | --- | --- |
| [Qwerty Learner](https://github.com/RealKai42/qwerty-learner) | 词汇练习、默写反馈与错词重练 | GPL-3.0 |
| [Lute v3](https://github.com/LuteOrg/lute-v3) | 在阅读中收集重点词 | MIT |
| [Kakugo](https://github.com/blastrock/kakugo) | 可中断的日语训练与按节奏复习 | GPL-3.0-or-later |
| [asbplayer](https://github.com/asbplayer/asbplayer) | 先听、后看文本、逐句跟读 | AGPL-3.0-or-later，部分 MIT |

以上是设计参考，不表示日日实现了原项目的全部功能，也不构成对其源码的再许可。实际包含的词库与录音见根目录 `THIRD_PARTY_NOTICES.md`。
