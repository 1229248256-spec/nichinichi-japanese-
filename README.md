# 日日 · Nichinichi

每天一点，日语更近一点。

一个面向中文母语者的日语学习网站：先恢复基础，再逐步准备 JLPT N2。默认每天 30 分钟，支持手机布局、灰白与炭灰主题、间隔复习和本机学习手账。纯 HTML、CSS、JavaScript，无需账号、API 密钥或后端。

## 现在可以做什么

- **30 分钟课堂**：7 节原创基础微课，按词汇、读音、语法、造句、听说、复习六步进行；未完成的课堂可继续。
- **词汇积累**：4,790 个词条，其中 320 张带搭配与原创例句的详解卡；其余主要提供读音、中文分义项和参考难度。支持搜索、筛选、优先学习和自添词句。
- **间隔复习**：简化的 1、3、7、14、30 天复习安排，默认每天最多 5 个新词，周日以旧词复习为主。不是 FSRS。
- **听音与听写**：220 条内置真人词音；未配音词条与课堂对话使用设备合成语音，界面分别标明。支持导入自己的逐词录音。
- **练习与手账**：基础诊断、语法练习、短文阅读、错题记录、教材学习进度与 JSON 备份。
- **手机使用**：底部导航、大字号选项、PWA 清单与离线缓存状态检查；可通过 HTTPS 部署后添加到手机主屏幕。

这是一套学习工具与起始内容，不是完整 N2 课程。N5—N2 标签来自社区词表，不能视为官方考纲；练习完成、看过词卡和实际掌握分别处理。语音合成不会自动评估发音，造句示例也不是 AI 批改。

## 本地运行

安装 Node.js 22 或更新版本，然后在仓库目录运行：

```sh
npm start
```

打开终端显示的 `http://127.0.0.1:4173`。无需 `npm install`，没有第三方运行依赖。修改 `dist/` 中的文件后刷新浏览器；如果调试缓存相关问题，可在浏览器开发者工具中注销 Service Worker 后再加载。

直接双击 `dist/index.html` 可以查看页面，但本地文件模式的存储、语音与安装能力取决于浏览器，建议通过本地服务运行。

## 部署到手机能访问的网址

把 **`dist/` 内所有文件**部署到支持静态文件的 HTTPS 托管服务。入口是 `index.html`，无需构建命令；路径均相对当前目录，支持部署在子目录。

iPhone 用 Safari 打开部署地址，选择“分享 → 添加到主屏幕”。首次保持联网，在“设置 → 手机使用指南”检查资源缓存，再自行测试断网打开。详见[手机使用说明](dist/手机学习使用说明.md)。真实 iPhone 上的安装、离线与声音播放仍需实机验证。

## 学习记录与隐私

学习记录保存在当前浏览器的 `localStorage`，自行导入的音频保存在 IndexedDB。仓库只包含空白状态的应用与教学数据，不包含任何人的学习进度。

电脑、手机、不同浏览器和不同网址之间不会自动同步。换设备或网址前先在设置中导出备份；导入会替换当前记录，个人录音不包含在 JSON 备份里。浏览器清理网站数据也可能清除记录。外部教材和词音来源链接由相应第三方服务提供。

## 开发与检查

```sh
npm test
```

检查包括原有 94 项 Node VM 回归测试，以及公开分发文件检查；覆盖词条对应关系、复习队列、备份确认、课堂进度、播放清理、安装提示与缓存状态逻辑。这些是模拟 DOM、存储和音频 API 的自动检查，不等于浏览器布局、真实声音或手机测试。

```text
dist/                 可直接部署的应用与学习内容
scripts/serve.mjs     无依赖本地静态服务
scripts/test.mjs      检查入口
tests/                模拟环境中的回归测试
tests/fixtures/       从固定版本词表提取的身份对照数据
docs/                 资源出处、音频校验与开发说明
```

增补词库、课程与音频的方法见[贡献说明](CONTRIBUTING.md)。请优先保留词条 ID，避免破坏已有复习记录。
